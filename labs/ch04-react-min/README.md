## 2. 改了什么 / 为什么

| 项 | 母本 | 这里 | 为什么 |
|---|---|---|---|
| 目的 | 演示 ReAct 能跑 | **对照实验**：同一问题跑「ReAct + 工具」与「一次提示词直接要 JSON」 | U5 验收要求"能讲清它与一次提示词输出 JSON 的区别"，所以要拿数据说话 |
| 工具 | `search` + 计算（依赖外部搜索） | `now()` + `calculate()`（全本地、零依赖） | 复现稳定，不受搜索接口波动影响 |
| 任务 | 旅行助手 | 「现在到 2026-10-07 还有多少小时 → 换算成天」 | 需要**模型不可能知道的实时事实**，逼出"必须调工具"的差别 |
| 工程 | — | 逐次保留版本证据（v1/v2/v3），把解析层的三个坑都留档 | 这份 lab 的价值一半在"怎么坏的、怎么修的" |

## 4. 真实输出（2026-10-02 实测，step-3.7-flash）

**v3（最终版）**

```
[路线A ReAct] 步数 4｜25.82 s｜3181 token
  第1步 行动: now()                        → 2026-10-02 10:29:03 (UTC+08)
  第2步 行动: calculate(expression="(24 - 10 - 29/60 - 3/3600) + 4*24")
                                           → 109.51583333333333
  第3步 行动: calculate(expression="109.51583333333333 / 24")
                                           → 4.563159722222222
  第4步 行动: Finish[到2026-10-07 00:00还有约109.5小时，换算成天约为4.6天]
  最终答案: 到2026-10-07 00:00还有约109.5小时，换算成天约为4.6天

[路线B 一次提示词] 6.63 s｜687 token
  输出: {"answer": "17472", "unit": "小时", "days": "728.0"}   ← 错的（模型凭记忆猜了个日期）
```

手工核对：10-02 10:29:03 → 10-07 00:00 = 13h30m57s + 4×24h = **109.52 h = 4.56 天**，与 ReAct 答案一致；对照组 B 差了两个数量级。

**三个版本（同一份代码的三次迭代，证据都在 `out/`）**

| 版本 | 现象 | 根因 | 结果 | token |
|---|---|---|---|---|
| v1 | 第 2–4 步连续报「表达式含不允许的字符」→ 耗尽步数，**无答案** | 解析层不支持 `name="值"` 写法，把 `expression="120 - 10 - 22/60"` 整串当成表达式 | 失败 | 4688 |
| v2 | 第 3 步「无法识别的 Action」，第 4 步模型自我纠正后给出正确答案 | `Action:` 正则跨行捕获，把模型**自造的 `Observation:` 行**也吃进来 | 成功但浪费一步 | 4244 |
| v3 | 4 步干净收尾，答案正确 | ① 支持 `name=值`；② `Action` 只取第一行；③ 检测并丢弃模型自造的 Observation | 成功 | **3181** |

（对应证据文件：`out/react_run_v1_parsebug.json`、`out/react_run_v2_multiline.json`、`out/react_run.json`）

**四条结论**

1. **ReAct 的失败绝大多数发生在"协议解析层"，不是"模型不会"**：同一个问题，模型三次都算对了逻辑，挂掉的是我的正则和参数拼装。母本提示词里那句"Action 必须在同一行"不是形式主义——是踩过坑的写法。
2. **一次提示词再省也没用，前提是它能知道事实**：路线 B 只花 687 token（是 ReAct 的 1/5），但答案是错的（17472 小时 vs 正确的 109.5 小时）。**便宜 + 错 = 更贵**（用户得自己发现错误）。这正好是 U2 判断清单里"目标说不清/需要外部事实"该上 Agent 的实例。
3. **模型会自导自演 Observation**：v2 里它一次输出里同时写了 `Action:` 和 `Observation:`（幻觉出工具返回值）。工程上必须把"观察"这一栏**只认自己执行的结果**，模型写的同类字段一律丢弃——否则等于让模型自己给自己编证据。
4. **重试与纠错是有成本的**：v1（3 次无效重试）4688 token vs v3（干净 3 次调用）3181 token，**差 47%**。把解析写稳，比换更强的模型便宜得多。
