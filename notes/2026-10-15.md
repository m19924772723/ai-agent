## 2. 核心概念（4 条，每条能回答「所以呢」）

1. **终止条件会扫描所有消息，包括任务文本本身**：`TextMentionTermination("TERMINATE")` 看每一条消息，任务描述里写"最后回复 TERMINATE"会让 user 消息一发出就满足条件、团队还没开工就结束（实测 0.0s/1 消息）——**所以**任务文本里不能出现终止词，要让角色在协作中自然说出它。
2. **UserProxyAgent 默认交互式**：无头环境（无 stdin）下轮到 UserProxy 会 `EOF when reading a line` 崩溃——**所以**自动化跑 AutoGen 必须给 `input_func` 注入"模拟用户"（返回 TERMINATE 即验收通过）。
3. **非标准模型要显式声明 model_info**：AutoGen 0.7 对不在白名单的模型（deepseek-flash 等）报 `model_info is required`——**所以**接 OpenAI 兼容端点时把 model_info（vision/function_calling/json_output/...）当必传参数。
4. **多智能体 = 职责分头 + 接力话术流转**：PM 拆需求→"请工程师开始实现"→Engineer 写码→"请审查员检查"→审查→"请用户代理验收"→UserProxy 说 TERMINATE——**所以**多智能体的价值在把任务拆成可各自聚焦的单元；每步都是独立 API 调用（本局 8 次）。
