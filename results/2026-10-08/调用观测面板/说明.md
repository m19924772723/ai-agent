# 成果 2026-10-08：Agent 调用观测面板（U10 单元）

> 五要素：做了什么 / 为什么 / 怎么验证的 / 关键输出 / 复现步骤

## 做了什么

1. **采集器**（`labs/ch12-observe/collect.py`）：6 次真实 LLM 调用，每次记录 输入/输出/延迟/token/finish_reason，落成 JSONL（追加式，可续采）。
2. **渲染器**（`render.py`）：把采集数据渲染成**自包含单文件 HTML 面板**——KPI 卡 + 逐行明细表（点行展开完整输入输出、异常帧红标），双击即开、无需任何服务。
3. **Langfuse 云版接入就绪**：SDK 4.17.0 已装；`collect.py` 检测 LANGFUSE_PUBLIC_KEY/SECRET_KEY/HOST，配齐即发云 trace，未配只落本地（不阻塞、无噪音）。

## 为什么

阶段2 U10 验收：「把 lab 的调用接入观测面板 → 面板里能看到 ≥5 次调用的输入/输出/耗时/成本」。本机没有 Langfuse 云账号（注册需邮箱验证，不替用户注册、不编造凭据），因此用「本地采集+自渲染」闭环**等值实现验收实质**，云版写成环境变量开关待用户配 key 即切换。

## 怎么验证的

| 项 | 证据 |
|---|---|
| 6 次真实调用可复现 | out/calls.jsonl + summary.json（ts/model/每次调用的五要素） |
| 面板数据真实渲染 | out/panel.html（6 次调用 6 行 + 6 个展开明细行，KPI 卡齐全） |
| 数字可追溯 | token 来自 usage 对象；成本列在无官方价目前显示「未定价」（不编数） |
| 云切换逻辑 | 未配 key 时日志提示仅本地采集；配齐才初始化 Langfuse（已 py_compile 通过） |
| 环境干净 | lab 独立 venv（D 盘解释器 + D 盘 uv 缓存），密钥全部来自环境变量 |

## 关键输出（实测数字）

- 6 次调用 / **2035 token** / 平均 **3158.8 ms** / 失败 0
- 单次延迟分布：1861.7 / 1912.4 / 2712.1 / 2867.6 / 4421.6 / 5177.1 ms（最慢/最快 2.8×）
- 分类 6 条全为合法 JSON、finish_reason 全 stop
- 面板 KPI：调用次数 6 · 总 token 2,035 · 平均耗时 3158.8 ms · 失败 0 · step-3.7-flash · 成本口径 未定价

## 复现步骤

```bash
cd D:/code/hermes/ai-agent/labs/ch12-observe
uv venv .venv --python 3.11
uv pip install --python .venv/Scripts/python.exe openai python-dotenv langfuse
export PYTHONIOENCODING=utf-8 LLM_MODEL_ID=step-3.7-flash LLM_BASE_URL=https://api.stepfun.com/v1 LLM_API_KEY=$HERMES_CUSTOM_STEPFUN_API_KEY
.venv/Scripts/python.exe collect.py     # 6 次真实调用 → out/calls.jsonl + summary.json
.venv/Scripts/python.exe render.py      # → out/panel.html（双击打开即面板）
# 云端切换：export LANGFUSE_PUBLIC_KEY=... LANGFUSE_SECRET_KEY=... 后重跑 collect.py
```
