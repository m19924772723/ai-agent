# 成果 2026-10-11：我的 3 个工具注册进框架（U15 单元）

> 五要素：做了什么 / 为什么 / 怎么验证的 / 关键输出 / 复现步骤

## 做了什么

把 U3 自写的 3 个工具（get_current_time 零参 / calculate / hours_until）注册进 hello-agents 1.0.0 框架，跑通"一问三调"任务，从框架自带 trace 提取工具调用证据；顺带修了框架的零参函数兼容 bug。

## 为什么

计划 U15~U17 验收：「把自己的 3 个工具注册进 chapter7 的框架跑通 → 日志证明工具被正确选择」。母本自带的搜索工具依赖 Tavily/SerpAPI 外部密钥，不装——改用我自己的零依赖三件套，正好验证"自己写的工具"进框架这条路。

## 怎么验证的

| 项 | 证据 |
|---|---|
| 3 工具全注册 | `agent.list_tools()` 含 get_current_time/calculate/hours_until |
| 模型正确选择工具 | trace 提取 step1 并行 3 个 tool_call，参数正确（{"input": "现在几点"} 等） |
| 工具执行成功 | 3 个 tool_result 无错误；时间精确到秒（证明真调用了 get_current_time，不是间接凑的） |
| 答案正确 | 2664 = (137+85)*12 ✓；距 2026-11-01 00:00 ≈490.56h ✓ |
| 可复现 | `register_my_tools.py` 一键重跑，证据写 `out/my_tools_run.json` |

## 关键输出（实测）

- 回答 12.69 s：现在是 **2026-10-11 13:26:32**（UTC+08）｜**(137+85)×12 = 2664**｜距今 **490.56 小时**
- trace 工具调用：3 次（step1 并行）→ get_current_time ✅ / calculate ✅ / hours_until ✅
- 工具全部成功 = True；框架自动增强 system prompt（首轮 1614 prompt token）

**踩坑（一手）**：① 框架 1.0.0 execute_tool 对函数工具位置式传参 `func(input_text)`，零参函数报错 → tool_adapter 按签名自适应修复；② 第一版"答案对、工具错"——get_current_time 失败但时间从 hours_until 结果间接凑出，只看最终答案发现不了 → 必须看 trace 逐工具核对；③ 证据在框架 trace（字段 event）不在 get_history。
