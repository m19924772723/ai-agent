# 成果 2026-10-04：框架探针（U7 单元）

> 五要素：做了什么 / 为什么 / 怎么验证的 / 关键输出 / 复现步骤

## 做了什么

装 `hello-agents` **1.0.0**（PyPI，`requires-python >=3.10`），用探针脚本搭一个带工具的 Agent，回答"框架替我做了什么"：

- 两条工具注册路径都验：`ToolRegistry.register_tool(CalculatorTool())`（框架自带）+ `register_function(word_count, ...)`（自注册）
- 任务：用计算器算 `(123+456)*7/3` 保留两位小数 + 统计 `'你好 hello'` 字符数
- 不只看输出，还读了**框架自己写的 trace jsonl**（每步 tool_calls / usage / 工具入参与返回）

## 为什么

`plan.md` 单元 U7 的验收：① 有一张类图；② 能讲清"框架帮我做了什么"3 条；③ 记下框架版本号。第 7 章讲的正是"自己实现 Agent 循环"——先量清框架边界，阶段4 自写 Loop 才知道该抄哪部分。

## 怎么验证的

| 项 | 证据 |
|---|---|
| 框架真在用 | 输出正确（1351.00 / 8 个字符），且 trace 里能看到两次 tool_call 与两次模型调用的 usage |
| 工具契约是框架做的 | trace step1 `tool_calls: 2`——**一次模型输出里并行两个调用**，执行与回填都是框架完成 |
| 状态与可观测性 | 框架自动创建 `memory/{sessions,todos,devlogs,traces}`、`skills/`、`tool-output/`，落 jsonl + html 轨迹 |
| 版本与 API | `hello_agents.__version__ = 1.0.0`；`SimpleAgent/ToolRegistry/CalculatorTool` 与书里一致；MRO 实测四范式并列继承 `Agent(ABC)` |
| 判据也验过 | 我脚本里手写的期望值（7）被证明是错的，正确答案 8，已改为 `len("你好 hello")` 由代码计算 |

## 关键输出（2026-10-04 实测，框架 1.0.0 + step-3.7-flash）

| 项 | 值 |
|---|---|
| 注册到的工具 | `python_calculator`、`word_count` + **框架自动加的 4 个**：`Skill`、`Task`、`TodoWrite`、`DevLog` |
| 调用轨迹 | step1：2 个**并行** tool_calls（计算器 + 字数），usage 1523/130/1653；step2：收尾，1619/122/1741 |
| 合计成本 | **3394 token** / 7.02 s / 2 步 / status=success |
| 答案 | `(123+456)*7/3 = 1351.00`；`'你好 hello'` = 8 个字符（都对） |

**三条结论**
1. **框架省掉的是"工具契约层"**：schema 下发、tool_calls 解析、执行、回填、并行调度都由它做——这层正是 U5 里我连踩三坑的地方。
2. **框架有状态**：默认把会话/待办/日志/轨迹写到当前目录，白送一套轻量可观测性；同时**自动注册 4 个内置工具**，首轮 prompt 因此到 1523 token（工具 schema 是真实成本）。
3. **1.0.0 的工具契约走原生 tool calling**（`_get_enhanced_system_prompt()` 不再拼工具说明）——与 U3 的结论方向一致，也说明网上"提示词拼接"的老教程对不上这个版本。
