# 成果 2026-10-13：框架内置工具实测（U17 单元）

> 五要素：做了什么 / 为什么 / 怎么验证的 / 关键输出 / 复现步骤

## 做了什么

读 hello-agents 1.0.0 的 tools/builtin/ 源码，把框架自动注册的 4 个内置工具（Skill/Task/TodoWrite/DevLog）逐个定位；再用 ReActAgent 实测：任务要求拆待办（TodoWrite）+ 记日志（DevLog）+ 作答，验证工具真实被调用、真实落盘。

## 为什么

计划 U17 验收"框架内置 Skill/Task/DevLog 工具实际用途"。U7/U15 一直看到这 4 个工具自动注册却从未深究——本单元补齐，且这是阶段3（第 8 章记忆）的前置认知。

## 怎么验证的

| 项 | 证据 |
|---|---|
| 源码定位 | 4 个工具 docstring/参数/落盘路径逐一读源码确认 |
| 真实调用 | trace 提取调用序列 ['TodoWrite', 'DevLog', 'DevLog'] |
| 真实落盘 | memory/todos/todoList-*.json（3 步清单+summary+stats）；memory/devlogs/devlog-*.json（decision 类目+tags） |
| 结构化完整 | 待办含 created/updated 时间戳与状态；日志含 id/timestamp/category/metadata |
| 可复现 | builtin_tools_probe.py 一键重跑 |

## 关键输出（实测）

- 调用序列：TodoWrite → DevLog ×2（16.97 s）
- **TodoWrite**：落盘 3 步 pending 清单（"调研→筛选→总结"），stats total 3 / pending 3
- **DevLog**：落盘 1 条 decision 类目日志，content 说明调研目的，metadata.tags=[agent, evaluation, metrics]
- **Skill**：本任务未触发（无需领域知识）——符合"按需加载"设计
- **Task**：源码确认（子代理隔离 + 工具过滤 + 摘要返回），未在本任务触发
- 回答：三个常用评测指标 = Success Rate / Task Completion Rate / Efficiency（效果/质量/效率三维）

## 四条用途结论

1. **TodoWrite** = 任务进度管理（声明式覆盖、单线程强制、跨会话可恢复）→ 第 8 章记忆前置
2. **DevLog** = 结构化开发日志（category+tags，决策可审计）→ 延续"看 trace 不看答案"纪律
3. **Skill** = 渐进式披露的知识加载（不进 system prompt，需要时注入 tool_result）→ 上下文工程早期形态
4. **Task** = 子代理上下文隔离（独立历史 + 摘要返回，避免主上下文爆炸）→ 多 Agent 协作方向
