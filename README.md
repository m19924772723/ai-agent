## 4. 每天怎么记（5 步，15–30 分钟）

1. **开笔记**：`cp notes/_模板.md notes/$(date +%F).md`
2. **定向学**：只学今天用得上的部分——先想清楚「今天要解决什么问题」，再去 `rg` 查对应章节。**不通读、不按目录顺序推进**。
3. **动手**：能跑代码的章节（第 4、7、8、9、13、14 章有完整代码）在 `labs/` 里跑一遍，把**真实输出**（片段、报错、耗时、token 数）粘进笔记。
4. **写四块**：读了什么 / 核心概念 3–5 条 / 能讲给面试官的一段话 / 用进哪个项目（见下节字段说明）。
5. **打卡**：把 `progress.md` 对应行的状态改成「在读 / 已读 / 代码已跑通」，并填笔记链接。当天提交（本地 git）。

## 5. 笔记模板字段怎么写

| 字段 | 合格写法 | 不合格（会被自己退回） |
|---|---|---|
| 今日主题 | 「第 8 章 记忆与检索：把 RAG 管线拆成 5 段，跑通 10_RAG_Pipeline_Complete.py」 | 「学习 RAG」 |
| 核心概念 3–5 条 | 每条一句话，且**能回答「所以呢」**：如「工作记忆 ≠ 长期记忆：前者是当轮上下文预算，后者要落库检索——所以 L3 的上下文预算必须显式管理」 | 抄教材小标题 |
| 动手记录 | 命令 + 真实输出 + 踩坑（怎么试的、结果如何） | 「运行成功」 |
| 面试话术 | 一段能直接说出口的话（3–6 句），含取舍与数字 | 概念名词堆砌 |
| 用进哪个项目 | 具体到 ai_pm 的路径与要改的文件 | 「以后有用」 |
| 遗留问题 | 明确写「不懂 X，下次先查 Y」 | 留空 |

## 6. 四条纪律

1. **当天记，不攒周末**——细节会忘，攒出来的是摘要不是笔记。
2. **只有真跑通 / 真读懂才打勾**。计划、别人讲的结论、AI 生成的解释，都不能冒充自己的学习成果。
3. **每篇笔记至少留一句能讲给面试官的话**。写不出来 = 这次学习没有产出。
4. **数字必须来自真实输出**（耗时、token、成功率、报错原文），不编不估。
